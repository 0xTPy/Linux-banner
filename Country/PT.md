Queres personalizar o teu terminal Linux? Estás no sítio certo!
Aqui podes exibir o logótipo da tua distribuição ou outro desenho com alguns comandos ao iniciar o teu terminal.

Passos:
  1) Abre o teu terminal e escreve o seguinte comando:
     ```bash
     nano ~/.bashrc
     ```

  2) Desce até ao fim com as setas do teu teclado.

  3) Quando estiveres bem no fundo, salta uma linha e cola a tua arte ASCII.

<p align="center">
                        =============================<br>
<b>                         /!\ AVISO /!\</b><br>
                        =============================
  </p>
No Linux, para copiar e colar num terminal não é CTRL + C / CTRL + V, mas sim:
CTRL + SHIFT + C / CTRL + SHIFT + V

No início de cada linha do teu ASCII, deves escrever echo " ...... ".

Podes ver os exemplos na pasta "ASCII-linux" para te ajudares!
